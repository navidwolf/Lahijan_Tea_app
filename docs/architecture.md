\# معماری پروژه TEA\_LAHIJAN



\## 1. هدف پروژه

این برنامه برای مدیریت کسب‌وکار چای طراحی شده است.  

کاربر می‌تواند اطلاعاتی مثل قیمت عمده هر کیلو چای، وزن خریداری‌شده و قیمت فروش را وارد کند.  

برنامه هزینه کل، مالیات، و سود نهایی را محاسبه و نمایش می‌دهد.



---



\## 2. ساختار پوشه‌ها

\- \*\*src/\*\* → کد اصلی پروژه

&nbsp; - \*\*main.py\*\* → نقطه شروع برنامه

&nbsp; - \*\*business\_logic/\*\* → شامل منطق اصلی محاسبات

&nbsp; - \*\*utils/\*\* → توابع کمکی

&nbsp; - \*\*config.py\*\* → تنظیمات عمومی مثل نرخ مالیات

\- \*\*data/\*\* → نمونه داده‌های ورودی/خروجی

\- \*\*assets/\*\* → شامل عکس‌ها و آیکون‌ها

\- \*\*tests/\*\* → تست‌های واحد برای بررسی صحت کد

\- \*\*docs/\*\* → مستندات پروژه

\- \*\*README.md\*\* → راهنمای کلی استفاده



---



\## 3. گردش داده

1\. کاربر اطلاعات (قیمت هر کیلو، وزن، قیمت فروش) را وارد می‌کند.  

2\. داده‌ها وارد \*\*calculations.py\*\* می‌شوند.  

3\. برنامه هزینه کل، مالیات و سود را محاسبه می‌کند.  

4\. نتایج در قالب متن فرمت‌شده به کاربر نمایش داده می‌شود.  



---



\## 4. توسعه آینده

\- اضافه کردن رابط کاربری گرافیکی (Tkinter یا PyQt).  

\- اتصال به دیتابیس برای ذخیره تاریخچه معاملات.  

\- ساخت داشبورد آماری (نمودار فروش و سود).
