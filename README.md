# Lahijan Tea App

اپلیکیشن مدیریت فروش و محاسبه سود چای لاهی‌جان.

## قابلیت‌ها
- محاسبه سود هر پاکت چای
- محاسبه سود روزانه با توجه به تعداد پاکت‌های فروخته شده
- ذخیره نتایج در فایل JSON
- امکان تغییر قیمت خرید، قیمت فروش، هزینه ارسال و بسته‌بندی

## نصب و اجرا
1. پوشه پروژه را کلون یا دانلود کنید.
2. به مسیر `src` بروید.
3. دستور زیر را اجرا کنید:
```bash
python main.py
